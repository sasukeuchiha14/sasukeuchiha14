### 👨‍💻 About Me

Welcome to my piece of the internet! I'm an Application Security Engineer and Cybersecurity Professional focused on securing applications, cloud infrastructure, and threat intelligence automation. I love breaking things to understand how they work—and then engineering robust defenses to secure them.

- 🛡️ **Application Security & Vulnerability Management:** Experienced in vulnerability ingestion, vulnerability lifecycle tracking, and risk remediation using **Qualys**, **Prisma Cloud by Palo Alto Networks**, and **Jira**.
- 📡 **Threat Intelligence & Security Automation:** Experienced in engineering Cyber Threat Intelligence (CTI) platforms leveraging **OpenCTI**, custom Python security scripts, and threat feed correlation (MITRE ATT&CK, CISA, CERT-In).
- 🚩 **CTF & Offensive Security:** Active CTF competitor with team **fSociety**, specializing in binary exploitation, reverse engineering, cryptography, and web application security.
- ⚙️ **IoT & Hardware Security:** Hands-on experience with Raspberry Pi & microcontroller security, including multi-factor authentication physical access control systems.
- ⚡ **Fun Fact:** My adrenaline is split evenly between clutching a 1v5 in-game and frantically submitting a captured flag seconds before a CTF timer runs out.
